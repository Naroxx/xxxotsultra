# XXXOTS ULTRA

Launcher i klient serwera **XXXOTS ULTRA** — https://ultra.xxxots.pl

- Pobierz launcher: [XXXOTSULTRA-Launcher.zip](https://github.com/Naroxx/xxxotsultra/releases/latest/download/XXXOTSULTRA-Launcher.zip)
- Rozpakuj do dowolnego folderu i uruchom `XXXOTS ULTRA Launcher.exe` — pobierze i zaktualizuje klienta sam.

`config/launcher.json` — wersje i linki, z których korzysta launcher.
